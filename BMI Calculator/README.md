# BMI Calculator

A small command-line program that calculates an adult's Body Mass Index (BMI)
from their weight and height, then displays the corresponding BMI category.

## Requirements

- Python 3.6 or newer
- No additional packages

## Usage

From the repository root, run:

```bash
python "BMI Calculator/bmi_calculator.py"
```

Enter your weight in kilograms and height in centimeters when prompted. The
program validates both values and reports the BMI rounded to one decimal place.

The categories use standard adult BMI ranges: underweight (below 18.5), normal
weight (18.5–24.9), overweight (25–29.9), and obesity (30 or above). These
categories are a screening guide and are not a medical diagnosis; adult BMI
ranges are not intended for children or teenagers.
